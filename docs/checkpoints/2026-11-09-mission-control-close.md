# 调度中心关闭窗口修复与验收

## 最终行为

调度中心识别同时支持系统 Dock 的 `mc` 根节点和 WindowManager 的
`mc.display` 根节点。可关闭的标准设置窗口支持 accessory 应用与 SuperIsland
自身；自身窗口按准确的 window number 执行 `NSWindow.performClose`。

Codex 缩略图与系统外框的边距可能超出旧规则。保留原有精确窗口匹配路径，
仅在外框不匹配时，以当前应用的系统缩略图标识和两像素以内的几何一致性
交叉核验。关闭前仍重新核对窗口身份、场景与几何；不扩大退出应用的范围。

## 已纠正的回退与恢复

中间版本 `20261109104125` 将系统缩略图检查设为全场景前置条件，用户反馈
所有按钮消失。`c19e835` 移除了该全局拦截，只针对当前候选执行必要核验。
该失败版本不可作为可用版本推荐；单元测试通过未能替代真实 AX 树验证。
