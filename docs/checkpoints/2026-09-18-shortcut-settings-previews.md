# WE1：文件删除与收起／恢复的设置预览

## 范围与版本

- 用户要求补齐“快捷删除文件”和“隐藏／显示所有窗口”的设置演示，同时询问扩展何时开放。
- 从干净提交 `171f258` 创建 `fix/we1-shortcut-settings-preview-20260918`；保留 `we1-105549-installed-20260918`、更早验收标签和应用备份。
- 沿用已确认 PRD 功能点 1 的悬停／键盘聚焦演示规则，按 feature-lifecycle-assistant B 类补实现遗漏。PRD、20260917 标注版本及原标注 ID 不变。
- 本轮仅修改设置 UI。删除执行器、窗口批次收起／恢复、Cmd-Tab、Dock、调度中心、扩展隔离和用户快捷键绑定均未修改。

## 实现

- 文件删除设置行采用现有快捷操作行的 hover/focus 行为，切换左侧演示，离开恢复总览；原开关、录制按钮、说明和标注 ID 保留。
- 新增纯 SwiftUI 虚构演示：选中文件进入废纸篓，保留未选文件并提示可恢复；没有读取或操作真实文件。
- “隐藏／显示”不再使用旧的仅隐藏视频。演示第一次收起 A/B、第二次恢复 A/B；原本已收起的 C 保持原状。
- 显示当前真实设置的快捷键，未绑定时显示“未设置快捷键”。没有写死用户截图中的 ⌘S／⌘D，也不修改绑定。
- 演示任务随离开、类别、绑定或减少动态效果状态变化而取消／重置。减少动态效果采用静态步骤，其中收起／恢复用双向箭头。VoiceOver 描述包含操作含义和当前快捷键。
- 视图不响应点击，不调用文件、AX、系统输入或窗口动作。

## 扩展开放结论

- 扩展已有源码，WE1 的设置与发现／激活入口主动隔离；现有 PRD 把扩展业务排除在 WE1 范围之外。未找到已确定的开放日期。
- 不能只删除门禁：WhatsApp 登录目录、Agents Status 端口／服务，以及正式 OAuth scheme 仍有与正式版冲突的边界。
- 建议单独安排扩展接入，先验证不依赖账号的番茄钟，再处理账号目录、端口、OAuth 和启停隔离。本轮没有开放任何扩展或读取授权状态。
