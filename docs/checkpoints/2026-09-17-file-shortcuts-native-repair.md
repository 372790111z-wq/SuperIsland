## 现场与范围

- 分支 `feature/we1-file-shortcuts-20260917`，从干净的 `81b1b1f` 接续；失败候选代码为 `73ec0ad`，安装构建号 `20260917182138`。
- 用户确认：第二次按隐藏/显示快捷键不能恢复，提示“没有可收起窗口”；桌面选中文件后快捷删除提示无法确认选择区域。
- 保留原 PRD 功能点 5、6 和标注版本 20260917。不是增加“恢复所有已最小化窗口”或修改删除范围。
- 仍保留 `we1-171017-accepted-20260916` 与对应稳定安装备份。当前失败版也完整备份为 `build/WE1-Debug/backups/Installed-SuperIsland-WE1-Debug-182138-before-native-repair.app`，101 项载荷/符号链接/模式一致且签名验证通过。

## 定位与修复

1. 原收起流程要求 AX 写成功后立即读回 true 才保存窗口引用；目标应用异步更新时，已接受的收起请求会丢失会话。现在立即保留已接受请求，仅接管初始明确未最小化的窗口；未知状态不当作成功，恢复未确认时继续保留。同一恢复请求完成后，下次快捷键可直接开始下一批。
2. 退出时继续等待本批恢复完成，重试每批仅激活一次原应用；失败请求不反复抢焦点。反馈区分“已请求”和读回确认，不能收起任何窗口时不提示已有恢复批次。
3. 只读采样抓到 Finder 前台桌面选中 1 项的实际路径：`AXGroup → AXScrollArea → exact Finder application`，三层明确非模态。旧首节点白名单拒绝 Group。现在仅支持该精确桌面路径且要求可读非空选区；初始、当前、最终三次快照都比较该 Group 的选中 AX 对象身份。普通窗口中的 Group 不获放行。
4. 另核实本机 Finder 文件列表使用 `(AXList, AXCollectionList)`，增加这对精确角色支持。编辑、对话框、未知选区、特殊子角色仍受原检查约束。
5. 旧文件快捷键要求整个 AX 探测阶段都保持物理按下，普通松键可能取消操作。现在合法按下领用后可松键，仍验证前台、注册身份、激活代次、焦点和选区；旧事件最多 100ms 内领用，整体期限固定在 Carbon 事件发生后 250ms，原始 release 立即取消未领用票据，防止旧事件借下轮按键执行。

没有操作用户的鼠标、窗口或真实文件；用户自行点选一次桌面文件供只读采样。采样只记录角色、布尔状态、计数与错误码，没有文件名、路径或内容。采样进程已停止。

## 实机边界

- 原失败版收起时丢掉的窗口记录不能安全补回；用户需先手动打开测试窗口，再用修正版连续收起/恢复。不能把所有原先最小化窗口重新纳入本批。
- 自动化测试、编译与只读采样不能代替新版真实按键/删除验收；等待用户复测 ⌘D 和桌面 ⌃D，快捷键保持原绑定。
- 不宣称执行了真实删除，也未代替用户确认 Finder 的任何弹窗。安装与最后静态检查结果附在后续记录。
