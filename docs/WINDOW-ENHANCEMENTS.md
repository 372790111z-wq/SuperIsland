# 窗口增强与快捷功能

在「设置 → 窗口增强」中打开总开关，再按需要启用各项功能。辅助功能权限用于定位和操作窗口；屏幕录制权限用于生成本地缩略图，未授权时使用标题模式。

设置中的动画是操作示意，不会真实删除文件或收起桌面窗口。悬停「快捷删除文件」或「隐藏/显示所有窗口」所在行，可查看对应示意和当前快捷键。

## 三个预览入口

| 入口 | 使用方式 |
| --- | --- |
| Dock 窗口预览 | 鼠标停在运行中的应用图标上查看窗口卡；点击卡片切换到对应窗口，最小化窗口可尝试恢复 |
| Cmd-Tab Plus | 按住 ⌘ 并用 Tab 选应用，查看窗口卡；用鼠标或 ↑／↓ 选窗口，点击卡片或松开 ⌘ 完成切换；Esc 取消 |
| 调度中心 Pro | 进入系统调度中心，把鼠标移到目标窗口，点击 × 关闭；也可使用设置中绑定的「关闭窗口」快捷键 |

Dock 和 Cmd-Tab 卡片的 × 只在能确认对应窗口可关闭时出现。关闭操作作用于选中窗口；应用有未保存内容时，仍可能弹出自身的保存确认。

缩略图和窗口操作是两项能力：系统无法取图时可能显示「窗口预览暂不可用」；只有旧截图、无法确认当前窗口身份时，卡片也可能暂时不可点击。主微信窗口取图仍有已知兼容性限制，不保证所有应用和窗口状态都能取到截图。

当前双微信适配针对主微信 `WeChat.app` 与已配置的 `WeChat-Work2.app`：Dock 分别显示；Cmd-Tab 在确认这两份安装身份后，可合并展示并标记窗口来源。它不是任意同名应用、多开工具的通用合并规则。

## Dock 窗口反转

开启「Dock 窗口反转」后，应用原本已在前台且有可见窗口时，再单击 Dock 图标可收起窗口。应用在后台或已最小化时，单击仍用于打开或恢复。

程序无法及时确认点击前的窗口状态时，会保留系统 Dock 的普通行为，因此非常快的点击可能不会额外收起。不要用此功能是否触发判断鼠标是否发生双击。

## 快捷删除文件

1. 在「快捷功能 → 快捷删除文件」中开启开关，录入自己习惯的快捷键。此功能默认关闭且未绑定。
2. 在 Finder 窗口或桌面中选中文件、文件夹。
3. 按设置的快捷键，调用 Finder 的「移到废纸篓」。需要恢复时，在废纸篓中操作。

功能只在 Finder 处于前台时处理选区。未选中文件、正在重命名或输入、弹出对话框、无法确认文件区域等情况下，会拒绝执行并提示原因。它不用于关闭窗口、清空废纸篓或永久删除。

文件删除和窗口收起／恢复已有用户实测反馈。首次桌面删除曾出现一次错误提示，后续操作正常；这条首次提示尚未定位，不能视为已修复。

## 隐藏／显示所有窗口

在「快捷功能 → 隐藏/显示所有窗口」设置快捷键后：

- 第一次按：收起本次能够操作的窗口，并记录这一批窗口。
- 第二次按：恢复刚才收起的那一批；原先已经最小化的窗口保持原状，已经关闭的窗口不会重新打开。
- 部分窗口恢复失败时，保留后续再次恢复的机会。

窗口是否能收起取决于应用和系统状态。例如部分全屏窗口不允许最小化，会保持全屏；不会为执行「收起全部」而自动退出全屏。

## 布局与多显示器

- 将窗口标题栏拖到屏幕边缘，可预览并应用对应布局。
- 拖窗进入悬浮分屏岛后，可选择二分、主辅或四宫格区域；在空隙松手或移出区域取消本次布局。
- 在设置中还可绑定布局、窗口居中、隐藏其他窗口，以及「移动到上个／下个显示器」。移动显示器与切换同一显示器上的桌面空间是不同操作。
- 「Dock 固定到显示器」开启后，还需选择目标显示器；程序回读成功后才显示为已固定。
- 快捷键框内的清除按钮可移除绑定；与现有绑定冲突时，会提示重新设置。

目标应用可能限制最小尺寸、缩放或全屏操作。出现「已调整，大小未达预期」等提示时，表示实际窗口没有达到完整目标布局；不能把提示当成精确落位的证明。
