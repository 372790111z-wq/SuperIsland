## 实现与确认

- 音量/亮度：支持键盘调节与控制中心音量、显示器亮度滑块拖动；读取真实状态，停止约 1.5 秒后恢复。用户在 r4 构建 20261014170439 上确认两项可以显示。r5/r6 原生运行树再次出现对应 HUD。
- 两种形态：按显示器安全区域判定。实体刘海屏在提示期间临时向两侧拓宽；无刘海屏采用完整胶囊。用户已确认拓宽方案。Mac mini 分支有几何测试，尚无另一台 Mac mini 的实机证据。亮度仅覆盖内置屏幕。
- Mac 通知：来源独立、默认关闭；本机已主动开启。只从系统可见横幅读取，不读取通知私有数据库或聊天历史，不上传消息。
- 来源降级：macOS 27.0.1（26A434）实测卡片仅暴露标题/正文。用户明确允许来源不明时显示“Mac 通知”，App 标识为空且无跳转；正文默认隐藏，全局隐藏优先。
- 事件身份：同一卡片短暂不可读取或被遮挡后重新出现不得重播；本次启用期间有界保留身份。不同卡片即使正文相同仍保持独立。系统复用同一 AX 卡片且内容完全相同的连续事件无法可靠区分，列为覆盖限制。
- 调节反馈优先、通知排队只引用现有记录；手动展开操作不被新通知强制切换。

## 历史失败与修复

- 初始居中 HUD 被实体刘海遮挡，用户批准提示期间拓宽；不改动已确认 HTML 历史快照。
- 控制中心拖动初版不触发，r4 加入仅在对应公开滑块上鼠标拖动的检测，用户复测确认。
- 系统共享屏幕通知原为关闭，测试期间经用户批准暂时允许；测试助手由用户确认通知授权后通过系统设置开启，持续样式用于定位。
- r5 修复全屏宿主与小卡片筛选；r6 增加宿主覆盖与来源容器标签识别，实测仍无来源标签；r7 加入用户批准的 Mac 通知降级后接通。
- r3/r4 中发现覆盖率插桩随产物进入，r5 起构建显式关闭；被拒候选与已替换版本保留，不将其当作最终 Release 交付。
- 原生工具不支持媒体键模拟；通知中心读取曾超时，未通过其他 UI 注入或权限数据库操作绕过。
