- 顶部挂绳开关使用现有 `SettingGroup` / `SettingToggleRow`，关闭时依赖控件仍可见并禁用。新操作与模态确认返回处再次检查启用状态；已经开始的编辑与文件交付仍允许按原流程完成。

- 保持唤醒复用唯一 `engine.enabled`，从运行策略中移到页首。关闭取消手动期限、暂停和完成后休眠请求；不取消外部任务或伪造任务完成。自动模式重开按既有真实未结束任务与保护策略判断。
- 普通及显示断言、实际合盖租约的恢复分别判断。尚有本进程持有的释放义务时，设置和菜单都不能再次取得保持。重试只处理本进程已有租约，不新增授权、不默认释放其他所有者；成功后仍关闭。
- 两个独立菜单栏图标保留；菜单总开关与设置共用服务状态。保持唤醒分区仍可只读导航，来源连接与授权操作关闭时禁用，必要的恢复/清理入口保留。
