## 2. 目标与范围

用户从独立挂绳图标菜单一次清空挂绳上的全部内容，不再逐张处理。包括图片、录屏、录音等已经入列的项目，涵盖分页中暂未显示的卡片；不能只清当前可见页，也不能按图片类型过滤。

清空包括两类效果：托管项目移除卡片，并将对应托管副本移到系统废纸篓；外部引用项目只移除卡片，外部原始文件保留。**不是清空整个托管目录**：编辑前备份、已导出文件、未在挂绳上的其他文件和其他 App 的内容不在批次内。不同项目引用同一物理文件时，只处理一次该文件，不误报失败或重复删除。

保留简单确认框与“下次不再询问”，并可在现有挂绳设置恢复询问。默认询问，无定时清理、永久删除、自动清空或新增快捷键。不清空系统剪贴板、不清空独立暂存架、不移除菜单栏图标、不更改监听或接管状态、不干预保持唤醒和外部任务。

当前原生模型已有 `image`、`recording`，现有入列验证覆盖图片及部分视频格式，尚无已验证的独立音频接收入口。HTML 的录音卡为清空范围示例；本需求要求清空逻辑覆盖全部已有项目，不新增录音采集、导入或转码功能，也不把原型音频卡当作原生支持证据。

## 4. 功能点

### SC2-F01 · 菜单入口与全部项目快照

- **业务目的**：让用户一次处理挂绳全部内容，并清楚区分挂绳列表与文件目录。
- **使用者**：本机 SuperIsland 截图挂绳用户，不引入管理员或账号角色。
- **触发**：开启挂绳后点击独立图标菜单“清空挂绳”。预留原生可访问标识 `si.sc.clear-all`，待实施后核验；此处不是已存在的 DOM selector。
- **流程**：读取全列表 → 检查启用、非空、非处理中 → 建立项目快照 → 按询问偏好进入确认或执行。当前分页和展开状态不限制范围。
- **规则**：快照按稳定项目 ID、当前路径和所有权绑定，不按媒体类型筛选；点击后新入列的内容不属于本批次。菜单数量来自同一列表，不另存业务计数。
- **边界**：空列表、模块关闭、重复点击均不创建批次；确认前不改变卡片、文件或剪贴板。保留原有展开、设置和独立图标。
- **数据**：批次 ID、快照项目 ID / 文件引用 / 所有权、快照数量、处理状态；沿用现有列表模型，不复制出第二套图库。
- **验收**：多页图片与录屏全部进入同一批次；支持的其他已入列类型不被过滤。无内容、关闭或处理中无法重复启动。确认期间新增项目保留至下一批。

### SC2-F02 · 简版确认与取消

- **业务目的**：清理前说明实际影响，同时减少阅读和操作负担。
- **使用者**：保持默认询问的挂绳用户。
- **触发**：SC2-F01 创建批次且询问偏好开启；预留 `si.sc.clear-confirm`、`si.sc.clear-confirm-suppress`。
- **流程**：展示第 3 节规定的标题、一句正文、复选框和两个按钮；取消 / Esc 直接关闭确认窗并返回原状态，不激活整个 App、不带出设置，也不新增取消提醒；点击清空才提交。
- **规则**：N 使用本批次快照数量。每次打开确认时复选框初始未勾选；取消不清理、不保存免询问选择。Enter 等键盘行为不能在首次显示时默认触发破坏性操作；确认期间不出现第二个相同弹窗。
- **边界**：模块在确认期间关闭则该批次取消；待处理内容变化时不得用旧快照授权清除新项目。执行过程中阻止重复提交，不用“取消”制造已经发生的文件操作被撤销的假象。
- **数据**：待确认批次、当前复选框值；复选框临时值与持久偏好分开。
- **验收**：取消、Esc、关闭模块均不删除；勾选后取消，下次仍询问。窄窗口、键盘及 VoiceOver 能读取标题、说明和控件，焦点可返回菜单入口。

### SC2-F03 · 托管副本进废纸篓与外部文件保护

- **业务目的**：同时释放对应托管副本的占用，保护用户外部原始文件并保持可恢复性。
- **使用者**：持有托管内容、外部引用或混合列表的挂绳用户。
- **触发**：确认清空，或已选择免询问后的菜单操作；沿用同一执行管线。
- **流程**：逐项复核快照与当前身份 → 核验所有权和文件边界 → 托管副本调用 macOS 废纸篓能力 → 成功后移除对应记录；外部引用只移除记录。最终校验列表持久化和实际结果。
- **规则**：托管身份需同时有可信所有权和位于本 App 允许的托管根目录内，不能只凭文件名、扩展名或路径字符串前缀。处理符号链接、路径变更及身份变化时，不得越界移动外部目标。不递归扫描和清空目录，不永久删除，不调用外部原件的“移到废纸篓”分支。免询问不跳过这些核验。
- **边界**：无法确认身份或存在不安全路径则保留并说明；原文件已缺失时可清掉失效引用，但不能计为成功移入废纸篓。文件正在写入、被编辑或不能安全处理时保留可重试，不截断或抢删。多个引用同一文件只发起一次文件操作；新引用不能因旧批次失去文件。
- **数据**：复用项目所有权及允许根目录；按物理文件身份去重，记录本批次处理结果。无需读取媒体正文，日志不保存图片、音视频、剪贴板正文或敏感完整路径。
- **验收**：使用隔离样例验证托管图片、录屏等能在废纸篓找回；外部原件、备份、导出、未入列文件及 ZIsland 目录完整。覆盖同名、路径边界、符号链接、缺失、只读及重复引用；不能用模拟结果代替真实文件验证。音频缺少实际入列能力时只验证通用清空管线，不声称录音采集已通过。

### SC2-F04 · 不再询问与设置恢复

- **业务目的**：让频繁清理的用户自行减少确认，且始终可以恢复保护。
- **使用者**：选择免询问或希望重新开启询问的本机用户。
- **触发**：确认框勾选“下次不再询问”并点击清空；或设置“清空挂绳前询问”。预留 `si.sc.clear-ask-before`。
- **流程**：勾选并确认时持久保存免询问；后续点击直接建立并执行快照。设置重新开启询问后，下一次恢复确认。关闭模块后设置仍可见且置灰，按 MS1 重新开启后可改。
- **规则**：默认询问；跨关闭、重新开启及 App 重启保留选择。旧的仅图片清理免询问状态不能默认为本次全部内容的授权；原生偏好沿用项目约定，网页演示 localStorage 键不直接搬为原生真源。该偏好只影响本批量动作，不改变单项外部文件删除确认、系统权限或安装确认。
- **边界**：取消、Esc 和未提交批次不保存。偏好读写失败时保留或回到询问并反馈，不假称“已记住”；本次已经确认的清理可继续，结果中说明下次仍询问。即使批次部分失败，用户已确认的免询问选择仍可保存，失败反馈不能因此消失。
- **数据**：一个持久布尔偏好 `askBeforeClearAll`（语义名，具体键在实施中按现有约定确定），默认 true；不另存互相矛盾的第二个“不再询问”值。
- **验收**：默认弹窗；勾选并确认后跨重启直接执行；勾选取消不生效；设置恢复后重新弹窗。注入偏好保存失败，仍保留询问并展示错误，不能默默关闭确认。

### SC2-F05 · 进度、结果、部分失败与重试

- **业务目的**：让用户知道实际清掉了哪些项目，失败时不丢内容、不误报完成。
- **使用者**：触发批量清空的用户，包含大列表和部分失败场景。
- **触发**：批次开始、每项返回、列表持久化返回以及再次点击清空。
- **流程**：显示“正在清空挂绳…” → 逐项累积结果 → 成功项移除、失败项保留 → 显示清空项数及失败数量；再次点击仅针对当时仍在列表的项目创建新批次，遵循当前询问偏好。
- **规则**：成功数量和废纸篓份数分别按真实结果计算；全成功与部分失败明确区分。无剩余项收起挂绳，有失败或新项目则保留其列表。清理结束不改模块总开关、独立图标或接收偏好；本批次成功项不能因为文件监听旧事件重新入列。
- **边界**：文件操作失败保留卡片，显示可理解的原因；索引写入失败不得显示全部成功。文件已移入废纸篓但索引未保存时要明确反馈并保留可恢复状态，避免重试重复移动或重启产生幽灵项。App 中断后需协调已完成文件操作与待保存记录，不能靠清空内存冒充完成。具体事务方案在实施阶段审查，不要求原型模拟操作系统事务。
- **数据**：请求数、移除记录数、实际废纸篓文件数、缺失引用数、失败集合、索引保存状态、必要的批次恢复元数据；不增加媒体内容副本。
- **验收**：一项失败其余成功，失败卡片和文件仍在且可重试；模拟索引失败、中途退出及重启，显示与实际文件一致。新到内容留存，空态入口置灰；免询问也能看到失败和结果。

### SC2-F06 · 并发、性能与既有功能兼容

- **业务目的**：批量清理时保护正在写入的内容和其他功能，保持界面与唤醒续租正常。
- **使用者**：同时截图、编辑、接收剪贴板或运行长任务的用户。
- **触发**：清空与新增、编辑、单项移除、总开关关闭或 App 退出交叠。
- **流程**：批次串行协调文件与列表变更；冲突项目重新核验或保留；新增项目进入下一批。文件工作不长时间阻塞 UI 主线程，已有保持唤醒监测及辅助程序续租继续运行。
- **规则**：同一项目不能被批量和单项动作重复处理；不能用旧快照覆盖晚到列表更新。处理中收到关闭 / 退出时停止未开始的破坏性工作，协调已发生结果并保留关闭意图；不能因此重新启用模块。只处理已完成、可安全核验的托管文件。
- **边界**：大录屏、多页列表、慢磁盘、权限变化、跨屏及菜单打开均应有反馈；无需联网，不新增后台扫描、权限或任务来源接入。正常关闭与异常退出必须分别验证。
- **数据**：共享批次状态、稳定项目身份和现有模块启用状态；不创建另一套监听、图标、任务聚合或计时器真源。
- **验收**：快速重复点击只产生一个批次；清理中新增不丢、编辑文件不被抢删；大文件清理时界面响应且唤醒监测 / 续租不间断。截图接收、单项操作、总开关、菜单同步、Chrome 和设置窗口移屏均无回归。

## 5. 实现与标注安排

现有复用位置为 `SuperIsland/Settings/ScreenshotLineFeature.swift` 的项目模型、菜单、设置、所有权判断、废纸篓和索引存储。不得简单循环调用可能弹出“删除外部原件”确认的单项 `trash`，也不得只把列表设为空或遍历整座托管目录。

## 8. 本轮实施与证据边界
