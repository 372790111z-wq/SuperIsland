# SuperIsland 窗口增强集成 PRD-WE1

## 基本信息

- 子项目：SuperIsland
- 任务类型：A 新需求
- 当前分支：`feature/window-enhancement-settings`
- 需求来源：已确认的 `prototype/superisland-window-enhancement-v0.1.html`
- 当前 Gate：HTML 已确认；用户已授权同步 PRD 后直接进入 Swift 实现
- 实施原则：保留 SuperIsland 深色独立设置窗口；窗口增强页的结构、悬停演示、布局卡、Dock 预览和 Cmd-Tab Plus 以本机 WINS 3.5 录屏为交互基准，不复制授权、试用、购买或激活内容

## 本次范围

本需求把窗口管理能力作为 SuperIsland 原生模块接入，包括设置与持久化、窗口布局快捷键、窗口移动与隐藏、边缘分屏、悬浮分屏岛、Dock 窗口预览与反转、调度中心增强、Cmd-Tab Plus、权限与降级。所有能力最终均需连接真实 macOS 窗口与辅助功能 API；HTML 演示结果不能作为代码完成证据。

明确不包含：试用、授权、购买、激活、支付、云端账户、远程配置和公开发布。

## 功能点 1：窗口增强设置与持久化

### 1. 业务目的

在 SuperIsland 现有设置窗口中提供统一、可理解的窗口增强配置入口，让用户能分别控制功能开关、快捷键、布局和高级行为。

### 2. 使用者

使用 macOS、允许 SuperIsland 管理窗口，并希望通过拖动、Dock、快捷键或调度中心提升窗口操作效率的用户。

### 3. 触发

用户打开 SuperIsland 设置并选择“窗口增强”。

### 4. 流程

1. 设置侧栏新增“窗口增强”，保留通用、模块、外观、扩展、高级和退出。
2. 用户分别启用核心能力、调度中心能力和快捷功能。
3. 用户为每个动作或布局录入快捷键。
4. 用户打开“高级…”设置调度空间、窗口间距、强调色和排除 App。
5. 设置变更立即写入本地持久化，并在下次启动恢复。
6. 鼠标移入或键盘聚焦核心功能、调度中心、快捷功能和布局时，左侧演示区即时切换对应效果。

### 5. 规则

- 总开关关闭时，所有窗口增强监听和快捷键停止响应，但保留子项配置。
- 子开关只影响对应能力，不得联动修改其他功能。
- 快捷键录入与功能开关独立；录入快捷键不得自动启用功能。
- 快捷键冲突时不得静默覆盖，必须显示冲突并保留旧值。
- 设置页面使用 SuperIsland 现有深色组件与尺寸，不嵌入 macOS 系统设置。
- Aero Shake、隐藏所有窗口和隐藏其他窗口只出现在设置项、悬停演示与真实快捷操作中，不提供自创的中央“窗口动作”选择面板。

### 6. 边界

- 辅助功能未授权时允许浏览和编辑设置，但执行窗口操作时明确提示授权。
- 屏幕录制仅用于窗口缩略图；拒绝后降级为窗口标题，不影响基础布局与移动。
- 排除 App 后，该 App 不响应窗口快捷键、分屏和预览。

### 7. 数据

- 使用 `UserDefaults` / `@AppStorage` 持久化总开关、子开关、快捷键、布局快捷键、高级设置和排除 App bundle id。
- 不保存窗口内容、缩略图或用户文档。

### 8. 验收

- [ ] 设置侧栏存在“窗口增强”，外壳与现有设置一致。
- [ ] 所有开关、快捷键和高级项可修改并在重启后恢复。
- [ ] 高级页不出现授权、试用、购买或激活。
- [ ] 15 个功能/快捷功能入口均有对应的移入或键盘聚焦演示，移出后回到总览。
- [ ] 权限缺失时不伪装执行成功。

## 功能点 2：窗口布局与快捷操作

### 1. 业务目的

让用户通过快捷键或拖动快速完成常用窗口布局、跨屏移动、居中和隐藏操作。

### 2. 使用者

频繁整理多个应用窗口或使用多显示器的用户。

### 3. 触发

用户触发已配置快捷键、拖动窗口进入边缘热区，或在悬浮分屏岛先选择分屏方案、再命中方案内的目标区域。

### 4. 流程

1. 系统读取当前前台 App 的可操作窗口。
2. 排除不可操作、全屏、系统层级或被用户排除的 App。
3. 根据目标屏幕的可用区域计算窗口 frame。
4. 执行移动和缩放，并给出成功或失败反馈。

### 5. 规则

- 设置页按 WINS 提供 10 个单窗口快捷键位置：左半屏、右半屏、最大化、左/中/右三分之一、上半屏、下半屏、左侧三分之二和右侧三分之二；每个位置可独立设置快捷键。
- 悬浮分屏岛只显示 4 个组合方案：左右二分、上下二分、左主右双、四宫格。方案是一级选择，方案内部区域是二级命中；不得把四宫格拆成四个一级按钮，其他方案同理。
- 四个四分之一区域是组合方案的内部目标，不在设置页重复生成四张快捷键卡。
- 快捷功能包括 Dock 锁定屏幕、隐藏所有窗口、隐藏其他窗口、移动到下个显示器、移动到上个显示器、窗口居中。
- 不支持缩放的窗口不得强制写入错误尺寸；移动可行时只移动并提示限制。
- 多显示器按系统排列顺序循环，断开显示器后重新计算目标。

### 6. 边界

- 没有可操作窗口时显示“没有可管理的窗口”，不执行空操作。
- 系统窗口、桌面元素、菜单栏、Dock 与 SuperIsland 自身窗口默认排除。
- 窗口最小尺寸、应用约束和屏幕安全区优先于目标布局。

### 7. 数据

- 输入：前台应用、AX 窗口、当前显示器、目标布局和用户设置。
- 输出：窗口位置与尺寸变更；不上传任何数据。

### 8. 验收

- [ ] 设置页只显示 10 个快捷键位置，不出现四张独立四分之一快捷键卡。
- [ ] 分屏岛只显示 4 个组合方案；在每个方案内部移动指针可分别选中其子区域，四宫格的四个区域落在正确象限。
- [ ] 6 项快捷功能只影响目标窗口或目标窗口集合。
- [ ] 不可缩放、无窗口、权限缺失和屏幕断开均有明确反馈。
- [ ] 排除 App 不响应上述操作。

## 功能点 3：窗口切换、Dock 与调度中心增强

### 1. 业务目的

把应用级切换继续细化到窗口级，并在 Dock 与窗口鸟瞰场景中提供可预测的预览、关闭、退出和反转操作。

### 2. 使用者

同时打开多个应用和多个窗口、需要快速定位具体窗口的用户。

### 3. 触发

用户使用 Cmd-Tab Plus、移入 Dock 图标、再次点击当前 App 的 Dock 图标，或进入 SuperIsland 的调度中心增强界面。

### 4. 流程

1. 读取运行中的普通应用与其可见窗口。
2. 有屏幕录制权限时显示本地缩略图；否则显示应用图标、窗口标题和数量。
3. 用户选择窗口后激活并前置。
4. 关闭窗口仅关闭选中窗口；退出程序必须二次确认并退出整个 App。

### 5. 规则

- Dock 窗口预览锚定对应 Dock 图标，不显示与该 App 无关的窗口。
- Dock 有屏幕录制权限时显示真实窗口缩略图，卡片为“App 名称—缩略图—窗口标题”结构；单窗口保持紧凑，多窗口横向排列。
- Dock 反转只在再次点击当前前台 App 时触发，不改变其他 App。
- 关闭窗口与退出程序必须是两个不同动作和快捷键。
- Cmd-Tab Plus 使用接近屏幕宽度的底部毛玻璃图标带；选中图标放大，具体窗口缩略图浮在该图标正上方，并随选择移动。

2026-09-11 用户确认的双微信规则：

- Dock 保持按安装路径隔离：主微信只显示主微信窗口，双开微信只显示双开微信窗口。
- Cmd-Tab 选到任意一个微信图标时，在现有窗口预览中展示两套已知微信安装的窗口；每张卡片标注“主微信”或“双开微信”，不新增实例选择步骤。共享是展示规则，不声称识别出了原生同名图标的唯一进程。
- 仅明确选择具体窗口后，才按该卡片真实进程和窗口身份激活或关闭。未选窗时松开 Command 维持系统原生切换；不得把共享列表首卡作为默认关闭或退出目标。切换图标、窗口关闭或失效时清理旧选择。
- 仅覆盖已确认的主微信与 WeChat-Work2 安装；其他同名应用、未知安装或强身份冲突不自动合并。原生切换器状态无法确认时，不执行延迟跨应用激活。
- 无操作对象的备用预览按各自安装展示并标为“应用预览”，不可激活或关闭；不把截图表面数量当成真实窗口数量。主微信透明截图问题仍单独保留。

### 6. 边界

- 受保护 App、无窗口 App、最小化窗口和跨空间窗口分别保留真实状态。
- 未保存内容是否可恢复由目标 App 决定；SuperIsland 不宣称可恢复。
- 系统不允许的 Mission Control 深度控制需以原生 PoC 结果为准，不用私有 API伪造完成。

### 7. 数据

- 只在本机短暂读取应用、窗口标题、frame、状态和可选缩略图。
- 不持久化缩略图，不上传窗口信息。

### 8. 验收

- [ ] Dock 单窗口、多窗口和标题降级态均可用。
- [ ] Cmd-Tab Plus 能选择具体窗口并正确激活。
- [ ] 两个微信 Cmd-Tab 入口均展示两套窗口且归属正确，Dock 仍分别展示。
- [ ] 从任一微信入口选另一套窗口后，松 Command 或点击均提交该真实窗口；无明确选择不改变原生行为，不误关共享首卡。
- [ ] 快速切图标、Esc、新一轮 Cmd-Tab、窗口退出或新鼠标点击后，不出现迟到激活或旧选择转移。
- [ ] 关闭窗口不会退出整个 App；退出程序有二次确认。
- [ ] 无法覆盖的系统级能力明确标记为受限或 PoC 未通过。

## 功能点 4：高级选项与权限边界

### 1. 业务目的

允许用户控制窗口布局细节并排除不应被管理的 App，同时清晰解释权限用途。

### 2. 使用者

需要定制台前调度、窗口间距、强调色或应用排除规则的用户。

### 3. 触发

用户在窗口增强设置页点击“高级…”。

### 4. 流程

1. 用户设置“预留台前调度空间”和“分屏窗口间距”。
2. 用户选择强调色。
3. 用户通过系统应用选择器添加或移除排除 App。
4. 用户查看当前 SuperIsland 版本或检查更新，点击“完成”返回。

### 5. 规则

- 强调色只改变窗口增强的热区、布局岛和选中反馈，不改变整个 App 主题。
- 排除 App 使用 bundle id 作为稳定标识，并显示真实 App 图标和名称。
- 本页不包含授权、试用、购买、激活或支付入口。

### 6. 边界

- 已卸载 App 仍可保留 bundle id，但显示“应用不可用”并允许移除。
- 系统应用选择器取消时不写入任何数据。

### 7. 数据

- 持久化台前调度、间距、强调色标识和排除 App bundle id 列表。

### 8. 验收

- [ ] 高级项修改后立即生效并持久化。
- [ ] 排除 App 可添加和移除。
- [ ] 页面不存在商业化授权入口。
- [ ] “完成”返回窗口增强主设置页。

## 实施顺序

1. 设置模型、侧栏入口、设置主页面与高级页面。
2. AX 窗口查询、10 种布局、居中、跨屏、隐藏与权限降级。
3. 全局快捷键注册、冲突校验和持久化。
4. 边缘分屏与悬浮分屏岛。
5. Dock 预览、Dock 反转与 Cmd-Tab Plus。
6. 调度中心增强 PoC；只把 PoC 通过的系统能力标记为完成。
7. 构建、真实 App 启动、辅助功能/屏幕录制权限与多显示器验收。

## 非目标

- 不修改现有提词器、通知、媒体、天气、日历或扩展业务。
- 不修改 bundle id、签名、权限 entitlement 或发布配置，除非实现所需且另行确认。
- 不提交、不推送、不创建 PR、不安装或替换当前运行中的 App。
