## 基本信息

- 日期：2026-10-16；版本：草稿 v0.1；类型：A，新功能。
- 状态：交互稿与本 PRD 已获用户确认，2026-10-16 已授权开始原生实现；安装、真实系统接管及完整实机验收仍分别记录。
- 交互参考：`../../prototype/screenshot-catch-v0.1.html`。其中按钮、缩略图、文件结果、系统设置与权限均为模拟；截图画面不是运行证据。
- 参考项目：[Tendedero](https://github.com/alejandrobujan/tendedero)，用于行为和视觉研究。SuperIsland 使用自己的名称、图标、代码与设置；参考项目的外部素材不自动进入产品。
- 原版试用观察：官方 Tendedero 1.5.0 在独立测试目录中确实收取新放入的图片；实物挂绳位于菜单栏下方，呈横跨屏幕的浅弧，卡片沿弧线居中。此观察只证明参考 App 的当次行为，不证明 SuperIsland 已实现。
- 本 PRD 仅管理 SuperIsland。ZIsland 在其仓库有独立 PRD；两款 App 的文件库、开关与运行进程各自独立。

## 目标、范围与既有约束

在桌面顶部提供一条与灵动岛和现有暂存架分开的弧形挂绳，快速收集刚产生的系统截图、录屏和经用户许可读取的纯图片剪贴板内容，支持复制、打开、拖出、标注、裁剪、保留和移除。用户可明确选择让 SuperIsland 接管 macOS 截图与录屏保存位置，也可只监听新文件。

用户已明确指定：**SuperIsland 与 ZIsland 都要完整能力，入口保留 Tendedero 式独立顶部挂绳**。用户还确认：两 App 接管切换必须先在旧 App 关闭再在新 App 开启；非接管模式下将外部原图拖到废纸篓须先确认；App 托管截图与录屏默认不限时保留，用户手动移除。

本需求不改变灵动岛展开逻辑、窗口增强截取、现有暂存架数据和系统截图快捷键。挂绳项不自动写入暂存架；用户主动拖入暂存架时才走既有输入语义。现有暂存架保留期不能自动清理挂绳内容。监听、接管和编辑均是本机行为；不上传图片、录屏或剪贴板正文。

与系统有关的前置边界：macOS 截图目的地和浮动缩略图是同一用户会话的全局偏好，不能假定两款 App 可各自独立接管。不同 macOS 版本实际使用的偏好键、录屏目标和授权行为必须在实现阶段核验，不以参考项目源码代替本机结果。

## 功能点 SC-01 · 独立弧形挂绳与可见性

- **业务目的**：让刚捕获的内容在桌面顶部随手可取，同时保持原有灵动岛的内容与尺寸。
- **使用者**：运行 SuperIsland 的本机用户。
- **触发**：新项进入、菜单栏“挂绳”入口、鼠标进入菜单栏附近，或用户设置的挂绳快捷键。HTML 演示默认 `⌃⌥T`，原生应允许修改并提示冲突。原生可访问标识预留 `si.sc.line`、`si.sc.menu`；落码后核对真实节点。
- **流程**：挂绳自菜单栏下方滑出，绳体两端淡出、中央浅幅下垂；卡片用夹子沿绳悬挂，随项目数保持居中。用户可手动收起；新内容按“短暂露出”设置提示，交互期间不自行收起。
- **规则**：挂绳为独立原生层，不把缩略图塞入岛体或暂存架；前后层级以不遮挡系统菜单栏与主要系统控制为准。默认只在当前桌面显示；全屏应用上显示需用户单独打开。减少动态效果时改用简化转场。绳曲率、夹子位置和卡片要随屏宽及项目数重新排布，不退化为平直横线或左贴边卡片。每张卡片的移除按钮位于左上角，密集排列时仍须可见、可点击。
- **边界**：空列表默认收起，用户手动展开时可显示绳与提示，不悬挂空卡；多屏、刘海、菜单栏自动隐藏、Space 切换、全屏及显示器断开均重算位置；屏幕太窄时卡片不能越界或重叠到无法操作。悬停不吞噬菜单栏原有点击。
- **数据**：`lineVisible`、`peekOnNewItem`、`showOverFullscreen`、`displayTarget`、`layoutItems`、`interactionSession`。几何尺寸由运行时布局决定，HTML 像素不是原生固定值。
- **验收**：空态、一项、三项及超过当前宽度可容纳项数分别检查浅弧、居中与左上角移除按钮可达性；岛收起/展开时互不改尺寸；至少在当前屏、外接屏、全屏与 Space 切换检查可见性和点击穿透。

## 功能点 SC-02 · 新截图监听与去重

- **业务目的**：不接管系统设置时也能快速拿到新截图。
- **使用者**：开启“监听新截图”的本机用户。
- **触发**：监视当前系统截图保存位置或用户明确选定的目录中的新文件；设置入口预留 `si.sc.watch-toggle`、`si.sc.watch-folder`。
- **流程**：先建立监听基线，再接收新写入的候选文件；文件写入完成并可读后生成缩略图、建立挂绳项；来源路径保留为引用。已有文件不批量导入。
- **规则**：只收可确认是新截图的支持格式，重复文件事件不得产生重复卡片；剪贴板、普通下载和其他 App 写入的同名文件不凭文件名猜成系统截图。不自动监视 ZIsland 的托管目录，即使它暂时成为系统截图目标；此时应提示监听受限。录屏自动进入挂绳的承诺限于接管模式或可可靠识别的监视来源；非接管下不扫描任意桌面视频。
- **边界**：目录迁移、文件仍在写、无权限、文件损坏、源文件被移动、系统保存到剪贴板或第三方应用时显示真实状态，不创建假卡片。监听失败后保留已有项，并在目录恢复时安全重建基线。
- **数据**：`watchEnabled`、`watchFolderBookmark`、`sourceURL`、`sourceIdentity`、`captureKind`、`createdAt`、`readiness`、`lastError`。路径书签和实际访问权限分开保存。
- **验收**：不接管时真实系统截图进入挂绳且旧桌面文件不被导入；重命名/重复文件事件不重复入列；目录撤权、写入中和损坏文件有可见失败或跳过结果。

## 功能点 SC-03 · 系统截图与录屏接管及恢复

- **业务目的**：使新截图与录屏直接进入 App 专用目录，同时能安全恢复原系统设置。
- **使用者**：在 SuperIsland 设置中明确开启接管的本机用户；这一操作影响该 Mac 用户会话的全局截图行为。
- **触发**：设置中的“接管系统截图与录屏”开关，预留 `si.sc.takeover-toggle`、`si.sc.takeover-status`。
- **流程**：启用前读取并持久化当前截图位置、录屏位置/目标、浮动缩略图等实际受影响设置及“原先未设置”的状态；检查当前接管者；确认可接管后建立 App 专用目录并配置系统；回读实际值确认成功，再启用对应监听。关闭时停止新接管、在确认系统值仍由本 App 持有的前提下逐项恢复原值，并回读验证。
- **规则**：默认关闭；不能静默修改全局偏好。ZIsland 正在接管时，本 App 禁止抢占，并提示用户先在 ZIsland 关闭，再返回开启；无法可靠判断当前接管者时也不得直接改写。同一全局快捷键被两 App 占用时，后注册者应显示冲突并允许改键，不让一次按键同时触发两个挂绳。本 App 自身重复启用不得覆盖第一次保存的原始快照。关闭或正常退出要恢复；异常退出后的下次启动先核对快照与当前系统值，再提供安全恢复，不无条件覆盖用户或第三方随后做的更改。接管状态只能在系统回读成功后显示为“已接管”。
- **边界**：设置读写失败、部分写入、系统版本键不同、目录不可写、另一个 App 中途修改、强制退出、重启、升级、两个 App 同时启动都要保留可诊断状态；部分成功要回滚本次实际写入或报告待恢复，不让 UI 显示虚假成功。外部已改动的键不可按旧快照盲目覆盖。
- **数据**：`takeoverRequested`、`takeoverEffective`、`originalPreferences`（逐键值与是否存在）、`ownedValues`、`snapshotTime`、`restoreStatus`、`managedFolderURL`。截图和录屏设置分别记录。
- **验收**：记录开启前系统值；真实截图与录屏进入专用目录；关闭后逐键回读与开启前一致；SuperIsland 与 ZIsland 并行运行时第二个 App 无法直接抢占；模拟异常退出和外部改键后不会误覆盖；接管失败时原设置可恢复且用户有明确信息。

## 功能点 SC-04 · 纯图片剪贴板输入

- **业务目的**：让用户复制的纯图片也能临时挂到绳上。
- **使用者**：主动开启“接收纯图片剪贴板”的本机用户。
- **触发**：剪贴板变化，设置入口预留 `si.sc.clipboard-toggle`。
- **流程**：在开关启用后观察后续变化；仅当剪贴板项是可读取的纯图片且无隐私/临时标记时，写入 App 托管图片副本并展示。关闭后立即停止观察。
- **规则**：默认关闭；不读取历史剪贴板，不导入文字、文件 URL、混合负载、隐藏或临时标记内容；不把剪贴板数据写入日志；同一次剪贴板变化只创建一项。来源标为“剪贴板”，与系统截图分开。
- **边界**：复制失败、格式不受支持、超大数据、内存或磁盘不足时不生成假成功；复制来自本挂绳的图片不应立即回流成重复项。
- **数据**：`clipboardEnabled`、`changeToken`、`contentType`、`managedURL`、`origin`、`createdAt`，只保存识别所需最小元数据。
- **验收**：默认关闭时复制纯图片无新项；开启后纯图片只入列一次；文字、文件、混合和带隐私标记内容均不入列；关闭后不再读取。

## 功能点 SC-05 · 卡片查看、复制与拖出

- **业务目的**：从挂绳快速把内容送到需要的 App 或文件夹。
- **使用者**：拥有有效挂绳项的本机用户。
- **触发**：单击、双击、右键、键盘操作或拖动卡片，预留 `si.sc.item`、`si.sc.context-menu`。
- **流程**：单击将截图作为图片复制、将录屏作为文件复制；双击在默认应用打开；右键提供打开、快速查看、复制、定位、编辑、移除及适用的保存操作；拖入 App 提供标准文件/图片数据并保留卡片；拖入 Finder 文件夹完成保存后从挂绳移除。
- **规则**：拖到文件夹对托管项执行可恢复的“保留”迁出，对外部引用项不得把原件从原位置擅自移动；应按来源选择复制或显式移动并向用户展示实际结果。只有接收方确认成功后才移除卡片。拖动取消、接收方拒收和复制失败均保留原项。图片与录屏显示类型区别与视频播放标识；无效操作不可伪装成可用。
- **边界**：源文件缺失、接收方不支持、文件名冲突、权限拒绝、大录屏和拖动跨屏有真实反馈；键盘与 VoiceOver 可达相同核心操作。
- **数据**：`itemID`、`kind`、`ownership`（外部引用/本 App 托管）、`sourceURL`、`managedURL`、`thumbnailURL`、`actionResult`。
- **验收**：真实图片与录屏各自执行复制、默认打开、快速查看和拖入 Finder/目标 App；取消与失败时原项存在；保存到文件夹后目标文件确实存在，才从挂绳移除。

## 功能点 SC-06 · 图片标注与录屏裁剪

- **业务目的**：完成常见的截图圈画和录屏片段整理，并让挂绳显示最新结果。
- **使用者**：选中有效截图或录屏项的本机用户。
- **触发**：长按或右键“标注/裁剪”，预留 `si.sc.edit`。
- **流程**：图片进入系统可用标注流程；录屏进入系统可用裁剪流程。编辑开始时保留可恢复原始数据；用户明确保存后写回本挂绳项并刷新缩略图、尺寸和文件信息；取消则保留原结果。
- **规则**：外部引用原件编辑前须明确处理副本/覆盖方式，默认不静默覆盖外部原件；托管项更新采用安全替换，写入成功前旧文件不丢。录屏不展示图片标注命令，图片不展示录屏裁剪命令。
- **边界**：编辑器不可用、读取失败、保存失败、源文件已移动、用户取消或多次快速打开时保持原件与原卡片，必要时提供重试。系统编辑器的实际可用性在目标 macOS 版本逐项核验。
- **数据**：`editSessionID`、`originalURL`、`workingURL`、`resultURL`、`editState`、`thumbnailVersion`。
- **验收**：截图实际保存标注后重新打开能看到改变；录屏实际裁剪后时长和缩略图更新；取消及故障注入时原文件可打开、卡片不丢。

## 功能点 SC-07 · 移除、废纸篓与默认保留

- **业务目的**：让用户知道移除卡片、扔进废纸篓和保存文件各自会影响什么。
- **使用者**：管理挂绳项的本机用户。
- **触发**：卡片左上角 `×`、菜单“从挂绳移除”、拖到废纸篓或关闭接管，预留 `si.sc.remove`、`si.sc.trash`。
- **流程**：点击左上角 `×` 等同“从挂绳移除”，只撤下卡片；外部引用原件保持原位。拖到废纸篓时先展示实际路径、所有权和影响，用户确认后调用系统可恢复的移到废纸篓操作；仅在成功后移除卡片。托管内容默认不限时保留，用户手动移除或明确移到废纸篓；关闭接管不清空既有文件。
- **规则**：没有自动过期清理。外部原图在非接管模式下拖废纸篓也必须先确认，取消则文件和卡片都不变。普通“移除”对托管文件的后续占用应有可见入口和明确的清理动作，不得留下无法管理的隐藏堆积；具体存储界面在实施设计中与本 PRD 对照。任何删除均不使用不可恢复的永久删除。
- **边界**：原件缺失、废纸篓失败、磁盘只读、多项同时操作、目录被其他程序占用时不宣称成功；本 App 不清理 ZIsland 的目录或系统其他位置。
- **数据**：`ownership`、`fileURL`、`retentionPolicy=manual`、`trashedAt`、`operationResult`、`fileExists`。
- **验收**：外部文件“移除”后原件存在；外部文件拖废纸篓确认前无变化，确认后能在系统废纸篓找到；取消保持原状；托管文件跨退出/重启仍在且可管理，关闭接管不自动删除。

## 与现有功能及实现验收的关系

1. SuperIsland 暂存架仍按 `docs/SHELF.md` 与现有 `ShelfStore` 运作；挂绳项目必须有独立所有权状态，不借用暂存架保留期或 `ShelfImages` 清理规则。
2. 已有窗口增强使用的 ScreenCaptureKit 权限与窗口缩略图逻辑，不等于本功能已经取得系统截图接管或文件目录访问能力；权限分别验证。
3. ZIsland 的接管状态仅作为冲突检测对象，不共享项目文件或用户数据；切换流程是“旧 App 关闭并恢复 → 新 App 开启并回读”。
4. 需要对照交互稿、正式 PRD、真实原生运行状态与原始文件结果验收。HTML 点击反馈、构建成功和设置开关可见都不算系统功能通过。

## 已确认的实施边界

已确认剪贴板监听默认关闭；新文件监听默认开启；全屏挂绳默认关闭；不自动同步暂存架；“移除”与“移到废纸篓”分开；外部文件标注先用副本；录屏非接管来源仅在可可靠识别时自动加入；双 App 快捷键冲突需提示；不自动读取另一 App 的托管目录。实际 macOS 版本的系统偏好键、编辑器能力、屏幕权限和跨屏窗口行为仍须以原生运行逐项验证。
