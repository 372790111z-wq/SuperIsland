## MB1-F01 · 三个独立显示开关

- **业务目的**：用户可自行决定菜单栏入口，不必改变正在使用的功能。
- **使用者**：SuperIsland 用户；无内置电池设备允许保存电池显示偏好但不显示不适用图标。
- **触发**：挂绳、保持唤醒、电池保护设置页的“显示菜单栏图标”；标识 si.sc.menu-bar-visible、si.ka.menu-bar-visible、si.bm.menu-bar-visible。
- **流程**：切换显示开关 → 保存对应显示偏好 → 创建或移除对应菜单栏项 → 保留功能启停与其他图标设置。隐藏后可回到设置重新显示。
- **规则**：开关位于功能禁用区域之外；功能关闭、恢复中或未授权时仍能设置图标显示。重复设置不创建重复图标。图标菜单可沿用既有功能启停操作，但显示操作本身不调用功能启停。
- **边界**：主 SuperIsland 图标隐藏不影响三个独立图标；功能启停不会改显示偏好；重启使用保存值。菜单栏空间不足时仍受 macOS 布局限制，不通过改变其他 App 或系统设置强行挤入图标。
- **数据**：menuBar.screenshotLine.visible、menuBar.keepAwake.visible、menuBar.battery.visible 三个布尔偏好，独立于 screenshotLine.enabled、保持唤醒引擎、电池保护启用意图和 general.showMenuBarIcon。
- **验收**：逐项覆盖启用开/关 × 显示开/关；跨偏好实例回读一致；反复显隐无重复残留；改变一个显示偏好不改变其他键、功能状态、权限和控制动作。

## MB1-F02 · 独立电池入口

- **业务目的**：需要时从菜单栏查看电量、进入电池保护设置，同时保持充放电控制独立。
- **使用者**：具备内置电池且选择显示的设备；未知读数可用中性未知状态，无电池时不显示。
- **触发**：电池显示偏好开启或电池能力/电量更新；原生标识 si.bm.status-item。
- **流程**：根据显示偏好和硬件存在性创建图标 → 展示当前电量或未知 → 点击菜单“打开电池保护设置…”进入既有设置。
- **规则**：菜单为只读状态与设置入口；不主动开启电池保护、不授权、不发充电或放电命令。未知读数显示问号与“电池电量暂不可用”，不显示红色 0%。
- **边界**：能力变为无电池时移除入口；能力恢复后按保存偏好恢复。偏好关闭时任何电量更新不能重新创建图标。无电池提示位于设置页，未影响原安全恢复入口。
- **数据**：复用 BatteryManager 的 presence、displayLevel、isCharging，不另开硬件扫描或创建并行控制状态。
- **验收**：已知电量/充电、未知电量、无电池、能力恢复、隐藏后数据更新、设置入口分别验证；显示操作不接触电池 helper。
