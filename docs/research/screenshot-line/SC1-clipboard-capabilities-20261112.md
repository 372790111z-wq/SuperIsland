原 SC1 PRD 的 SC-04 规定纯图片接收，排除混合负载及临时标记。该历史 PRD、HTML 和 annotation 快照保持不变；当前实现的混合图片及稳定临时图片接收规则以本补充为准。原开关配置键和 accessibility 标识继续复用，界面名称改为“接收剪贴板图片”。

## 接收规则

- 开关默认关闭；开启或重启只观察后续变化，关闭期间的剪贴板不会补收。
- 单个剪贴板项只要包含可解码的 PNG、TIFF、JPEG 或 HEIC 静态图片，即可接收。允许同时附带文字、文件地址、网络地址和任意应用元数据，但不请求这些附带数据的正文，不跟随地址、下载或读取地址指向的文件。
- 第一种图片表示损坏时尝试下一种表示。应用升级或更换应用本身不影响判定，实际输出的数据格式仍必须受支持。
- ConcealedType 和 AutoGeneratedType 标记优先拒绝，且不请求图片数据。TransientType 不再一律拒绝：等待连续两次轮询观察到同一剪贴板 generation 后接收，通常增加约 0.6–1.2 秒等待。稳定性不是来源认证，无法判断每个应用的真实意图。
- 读取和转换后再检查 generation；读取期间被替换则丢弃旧快照。后续新内容仍可继续接收。
- 编码数据和输出 PNG 均不超过 64 MiB，像素数不超过 64 Mi，单边不超过 32768。解码前检查尺寸，按 EXIF 方向转换，不缩小原分辨率。
- 多项剪贴板、多帧图片、纯文字、纯地址和没有可用内嵌图片的文件不接收。不是承诺任意格式、任意未来版本都能显示。
- 图片仍保存在原托管 Clipboard 目录，保留现有重复图片去重、自身复制不回收、清空事务、记录持久化和展示路径。图片来源不冒称系统截图。

本机现有剪贴板的只读探针确认：一个含 PNG/TIFF、文件地址、应用元数据和 TransientType 的项可被新解析器解码，读取前后 generation 相同。只记录类型、成功状态和尺寸；未保存图片正文或读取附带正文。该探针证明解析成功，尚不等于安装后完整截图流程验收，也没有据此宣称其他应用已经实测。
